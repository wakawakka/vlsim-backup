vlsim-backup

A private backup tool of one software project. It is not a public service.

vlsim-backup copies the working files of a simulator project from its owner's computer to the owner's own Google Drive, so that they are not lost. It runs on the owner's machine on a schedule and sends only new and changed data.

  • It uses the Google Drive API with the drive.file scope only: it sees and changes only the files it created itself, not the rest of the Drive.
  • The copies are stored only in the owner's Google Drive.
  • Only the owner of the project uses it.
