Privacy policy

vlsim-backup, effective 18 November 2026

What the app is

vlsim-backup is a private backup tool. It copies the files of one software project from its owner's computer to the owner's own Google Drive. Only the owner of the project uses it.

What Google data it accesses

The app asks for one permission: the Google Drive API scope drive.file. With it the app can see, create, change and delete only the files and folders that it created itself. It cannot see any other file in the Drive, the account's email messages, contacts or any other Google data.

How the data is used

The app writes backup copies of the project's files into a folder in the owner's Drive, reads them back to check them and to restore files, and deletes old copies that are no longer kept. It does nothing else with the data.

Where the data is stored and who gets it

Backup copies are stored only in the owner's Google Drive. The access token is stored only on the owner's computer. No data is sent to the developer, sold, shared with or transferred to anyone else, and none is used for advertising, analytics or training of AI models.

How to remove access and data

Access can be withdrawn at any time on the Google Account page myaccount.google.com/permissions. The backup copies can be deleted from Google Drive like any other files.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
